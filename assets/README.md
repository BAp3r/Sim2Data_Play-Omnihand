# 资产目录约定

- `external/`：官方资产库的只读挂载/链接入口，已忽略；可直接使用外部根路径，不要求本地复制。
- `resolved/`：解析实际路径后生成的本机 override USD，已忽略；不把机器路径写入公开 USD。
- `owned/`：自建或明确获授权的安装件/场景小资产，USD、Blender 等按根 `.gitattributes` 走 LFS。每个产物保留来源、单位、版本和许可记录。

目录目前只定义存放规则，不表示真实资产已绑定。官方全集、原始实录和数据集不纳入这里的公开版本历史。其他需要配置的项目见 `docs/CONFIGURATION.md`。
