# B_SCENE 参数需求清单

本清单只表达已批准的坐标约定、视频支持的布局关系和待测输入，不填入猜测的机器人参数。世界坐标沿用 `docs/DESIGN.md`：桌面中心表面为原点，`x` 指向操作者右方，`y` 远离操作者，`z` 向上；`T_A_B` 把 B 中的列向量映射到 A，四元数序列化为 wxyz，长度单位为米。

## 已有证据

- 主会话批准观察包 `OBS-M1-20260922-ROOT-01`（`approved_topology_only`，审阅者：主会话）仅批准拓扑关系：双臂在桌面同一侧、法兰与转接件分离、审阅近侧画面可见手根下方有独立腕相机总成、桌面上方有独立主相机支架；两只手下均装 D405 来自用户确认。该包不能解析尺寸、SE(3)、修订、解剖手侧、内参、质量/惯性或驱动映射。
- 两段手机实录经解码后为横向 1440×1080 展示帧；这是手机参考视频属性，不是任一训练相机的分辨率、内参或频率。
- 全景画面显示两套 AIRBOT Play + OmniHand 2025 位于桌面同一侧并朝同一工作区伸出；不能由画面量出两个底座的间距、旋转或桌面尺寸。
- 约 11.58 s 的画面显示桌面上方有升高支架和伸出的相机支臂。主相机可以在仿真中选用通用相机，不能把手机绕拍视角当作主视角的实测外参。
- 约 3.86 s 和 0.37 s 的画面显示手根、黑色法兰、银色转接板/支架和下出线缆的装配关系。用户说明两只手下均装 RealSense D405；D405 的完整光学姿态、流配置和内参仍须从相机配置或标定获得。
- 用户给出的转接长度约 4 cm 只保留为名义描述，不能展开成 `[0, 0, 0.04]` 或任何完整 6D 变换。

## 原子坐标链

每一侧都必须独立填写以下边，不能用派生的 `T_flange_hand_root` 或 `T_parent_color_optical` 代替原子输入。所有值使用米和 wxyz 单位四元数；当前值继续为 `null`。

| 链 | 原子边 | 当前状态 |
|---|---|---|
| 手装配 | `T_world_flange → T_flange_mount → T_mount_hand_root` | 世界底座/法兰、转接件和手根外参待实测 |
| 腕相机 | `T_mount_camera_housing → T_housing_color_optical` | 左右 D405 housing 和 color optical 外参待实测 |
| 抓取 | `T_hand_root_grasp_tcp` | TCP 定义、指端/掌心关系待确认和实测 |
| 光学扩展 | `T_housing_depth_optical` | depth 关闭；只有扩展 depth schema 后才补 |

运行时按 `T_world_flange × T_flange_mount × T_mount_camera_housing × T_housing_color_optical` 组合腕相机世界位姿；手根链由 `T_world_flange × T_flange_mount × T_mount_hand_root` 组合。链工具只组合已给变换，不估计标定。

## 必须先补齐

`scene_requirements.py` 是机器可读的需求分类清单；其中部分 key 是分类 ID，不能直接当 JSON 字段路径。实际草案字段路径由 `preflight.required_paths()` 列出，本地检查确认这些路径在草案存在；这仍不是动态标定或物理验收。正式采集前至少需要：

1. 两臂准确的 AIRBOT Play 资产/版本、OmniHand 变体/修订/左右侧、底座世界位姿、法兰到转接/手根/TCP 的完整 SE(3) 链。
2. 转接和相机支架的完整 6D 变换、尺寸、质量、惯性和碰撞几何；实测值不能由视频透视估计替代。
3. 左右腕 D405 的 housing、color optical 变换，各路 RGB 分辨率、配置、内参、畸变和时间标签；实际流配置冻结前不得补黑帧。仅在启用 depth 时再要求 depth optical 变换与深度流配置。
4. 双臂共达的桌面中转区域；右臂可达性及桌外右侧框子的位姿、尺寸、支撑高度；源物体的放置、尺寸、质量和刚性假设。
5. 绑定官方资产后做场景打开、初始穿透、遮挡和标定板投影检查。当前 M0 无 Isaac Lab/官方资产绑定，因此这些验证未运行。

## 仍为 null 的生产输入

桌面尺寸/高度、左右底座世界位姿、两侧完整法兰到转接到手根变换、两侧 TCP、转接/相机安装件尺寸质量惯性碰撞、左右 D405 housing 与 color optical 外参、腕部 RGB 流配置/内参/畸变/时间标签、中转区、外框位姿尺寸和支撑高度、右臂可达性、源物体尺寸质量和刚性假设均未提供。主相机世界位姿和覆盖验证也未提供。

主相机型号和内参可以采用 `synthetic` 设计值，但位姿和覆盖仍是必需输入。缺失世界位姿会阻断采集，不能宣称还原实拍主相机；本清单完成不等于 M2 场景验收。
